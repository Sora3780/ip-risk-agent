# 제품 기획서 — 스마트 스크롤 (Smart Scroll)

## 1. 개요

모바일 단말의 전면 카메라로 사용자의 시선을 추적하여, 화면을 손대지 않고
문서를 자동으로 스크롤하는 기능이다. 뉴스 앱과 전자책 뷰어에 우선 탑재한다.

## 2. 핵심 동작 방식

1. 전면 카메라 영상에서 얼굴 영역을 검출하고, 눈동자의 중심 좌표를
   실시간으로 추정한다.
2. 눈동자 좌표가 화면 하단 20% 영역에 일정 시간(기본 0.8초) 이상 머무르면
   스크롤 다운 이벤트를 발생시킨다.
3. 스크롤 속도는 시선이 하단 경계에 가까울수록 비례하여 빨라지도록
   가변 제어한다.
4. 사용자가 화면에서 시선을 떼면(얼굴 미검출 2초) 스크롤을 자동 정지하고,
   재검출 시 마지막 위치에서 재개한다.
5. 조도가 낮은 환경에서는 화면 밝기를 일시적으로 올려 눈동자 검출률을
   보정한다.

## 3. 부가 기능 — 시선 잠금 해제

잠금 화면에서 화면에 표시된 4개의 무작위 지점을 사용자가 시선으로
순서대로 응시하면 잠금이 해제된다. 기존의 슬라이드 방식 잠금 해제와
패턴 입력 방식을 시선 궤적으로 대체하는 것이 특징이다.

## 4. 단말 요구사항

- 전면 카메라 30fps 이상
- 온디바이스 얼굴 검출 모델 (외부 서버 전송 없음)
