# IP DeteDog

작업공간 변경 기반 IP 리스크 상시 점검 도구.

로컬 폴더와 Google Drive 의 파일 변경을 감지해, 그 시점에 오픈소스 라이선스 위험과
선행 특허 후보를 점검하고 위험 등급·원문 근거·후속 조치를 함께 제공한다.

아주대 AI 부트캠프 · PBL 1차 MVP · 5조

---

## 만든 이유

라이선스와 특허 확인은 **사람이 시작해야만** 이뤄진다.
패키지마다 원문을 찾아 읽어야 하고, 특허는 KIPRIS 에서 검색어를 직접 구성해야 한다.
그래서 확인은 미뤄지고, 문제는 기능 개발이 끝난 뒤에 드러난다.

검사 도구가 없지는 않다. 다만 전부 실행 시점이 사람에게 달려 있다.
이 프로젝트는 **검사의 시작점을 파일 변경으로 옮기는 것**을 목표로 한다.

## 동작 방식

```
작업공간          변경 감지              입력 정규화          분석                결과
로컬 폴더    →   파일 이벤트       →   파일 위치       →   라이선스 규칙   →   위험 목록
Google Drive     최종 수정 시각 비교      변경 유형            RAG 근거            상세 근거
                                        변경 내용            KIPRIS·Gemini       변경 이력
```

입력 출처가 달라도 서버로 들어갈 때 형식을 통일하므로 검사 경로는 하나다.

### 라이선스

1. 의존성 파일에서 외부 라이브러리 추출 (하위 폴더 최대 5단계)
2. [deps.dev](https://deps.dev) 로 SPDX 식별자 조회, `non-standard` 응답은 PyPI 메타데이터로 보완
3. 소스 헤더의 라이선스 표기와 출처 누락 확인
4. SPDX 기반 자체 규칙으로 등급 판정 — `FORBIDDEN` / `RESTRICTED` / `REVIEW` / `NOTICE`
5. 문서에 적힌 라이선스와 실제 사용 라이브러리 대조

**등급은 규칙이 정하고, 설명만 모델이 만든다.** 같은 입력에는 같은 등급이 나온다.

### 근거 (RAG)

한국저작권위원회 오픈소스SW 라이선스정보 84종을 149개 조항으로 나눠 768차원으로 색인했다.
원문 전체를 넣지 않고, 문제가 된 라이선스로 후보를 좁힌 뒤 관련 조항 **3건만** 전달한다.

### 특허

문서 내용이 실제로 바뀌었고 · 최소 10분이 지났고 · 잔여 한도가 있을 때만 검토한다.
Gemini 가 영문 2~3단어 검색어 5~6개를 만들고, KIPRIS 검색 결과를 출원번호로 합쳐
반복 등장한 후보 상위 6건의 초록을 비교한다.

모델이 제시한 인용은 **원문에 실제로 있는지 문자열로 다시 확인**하고, 없으면 버린다.
결과는 초록 기준 기술 유사도이며 침해 판단이 아니다.

## 실행

```bash
pip install -r requirements.txt
cp .env.example .env          # 키를 채운다
python scripts/build_index.py # RAG 인덱스가 없을 때만
python scripts/launch.py      # 서버 + GUI
```

Windows 에서는 `IP DeteDog 실행.bat` 을 더블클릭해도 된다.

`GEMINI_API_KEY` 가 없어도 **규칙 판정과 등급 표시는 동작한다.**
설명 생성과 특허 검토만 비활성화된다.

### 필요한 키

| 환경 변수 | 용도 | 없을 때 |
|---|---|---|
| `GEMINI_API_KEY` | 설명 생성 · 특허 검색어 · 유사도 비교 | 규칙 판정만 동작 |
| `KIPRIS_API_KEY` | 선행 특허 후보 검색 | 특허 검토 비활성 |
| `GOOGLE_DRIVE_CREDENTIALS` | Drive 감시 (서비스 계정 JSON 경로) | 로컬 폴더만 감시 |

서비스 계정에는 **읽기 전용**(`drive.readonly`) 권한만 요청한다.
감시할 폴더를 서비스 계정 이메일에 뷰어로 공유해야 읽을 수 있다.

## 검증

```bash
python scripts/score.py          # 라이선스 정확도
python scripts/test_personas.py  # 폴더 형태 5종 회귀
python scripts/test_patents.py   # 특허 사례 3종
python scripts/check_secrets.py  # 비밀정보 점검
```

| 항목 | 결과 |
|---|---|
| 라이선스 재현율 | 6 / 6 |
| 라이선스 정밀도 | 6 / 6 (오탐 0건) |
| 근거 인용 | 5 / 6 (미상 라이선스 1건 제외) |
| 사용 환경 회귀 | 5 / 5 |
| 특허 사례 | 3 / 3 (정상 기획서 후보 0건) |
| 최초 전체 검사 | 9.8초 |
| 변경 없을 때 | 0.0초 · 외부 호출 0건 |

소규모 고정 테스트셋 기준의 **회귀 결과**다. 일반적인 정확도 지표로 해석할 규모는 아니다.

## 하지 않는 것

- **법적 판단** — 청구항 침해 여부와 라이선스 위반의 법적 결론은 다루지 않는다
- **특허 청구항 전문 대조** — KIPRIS 제공 범위가 초록이다
- **후보 전건 판정** — 상위 6건만 본다. 대신 후보 수·판정 수·미판정 수를 함께 표시한다

## 남은 과제

- Drive 주기 확인 → 변경 알림 기반 즉시 검토 (배포 필요)
- 변경 파일 단위 증분 검토 (현재는 판정·설명 단계만 캐시)
- 공유 워크스페이스 · 파일 단위 최소 권한
